# sum-app

The app for the day-to-day operations of the Schoenstatt University Men (SUM)
in Austin, Texas.

## What it is

- **For the members.** Every member of SUM has a login. Alumni may be given
  one in the future.
- **Installed from the browser.** It is a progressive web app: open it in
  Chrome or Safari and add it to the home screen. Its `manifest.json` makes it
  open like an ordinary app on a phone, with nothing to download from an app
  store.
- **Served by Go.** A Go HTTP server hosts the app's static files.
